# Частный сканер — Android APK (прототип v0.1)

Независимое Android-приложение, не связанное с Adobe. Репозиторий CRM в ветке main не изменяется.

## Реализовано
- Захват документов через Google ML Kit: автоматическое определение границ, коррекция перспективы, кадрирование, фильтры, многостраничное сканирование, импорт изображений.
- Сохранение PDF в Documents/PrivateScan в локальном хранилище Android без обязательного облачного аккаунта.
- Просмотр списка PDF, поиск по имени, открытие, отправка, переименование, удаление.
- Системное окно передачи PDF с ограниченным временным разрешением чтения.

## Ограничения
- **Не полный аналог Adobe Scan**. Нет OCR (в частности русского), поиска внутри текста PDF, редактирования уже сохраненных PDF, облачной синхронизации, парольной защиты, сжатия PDF и электронной подписи.
- Захват реализован с помощью Google Play services. Для первого запуска могут понадобиться интернет и скачивание компонентов; устройство без Google Play services может не работать.
- PDF сохраняются локально, но в папке Documents, доступны другим приложениям с соответствующим доступом. Не используйте этот прототип как защищённое хранилище адвокатской тайны.
- APK собран с debug-подписью только для тестирования; проверка на устройстве обязательна.

## Как получить APK
Откройте Actions -> PrivateScan APK -> последняя успешная сборка -> Artifacts -> PrivateScan-debug-apk.
В архиве находится app-debug.apk. На Samsung разрешите установку из выбранного источника только на время установки.

## Сборка вручную
Android SDK Platform 35, Java 17, Gradle 8.10.2:
```
gradle -p scanner-app :app:assembleDebug
```

## Конфиденциальность
Выполнено отсутствие разрешений Android INTERNET, CAMERA, READ_MEDIA_* в самом приложении. При этом сторонний компонент Google Play services выполняет сканирование и динамически загружается; следует учитывать условия и политику конфиденциальности Google.
