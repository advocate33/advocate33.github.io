# PrivateScan — Частный сканер Android v0.2

Независимое приложение для Android (не Adobe и не официальный клиент ChatGPT).

## Функционал
- Сканирование камерой и импорт изображений через Google Play services ML Kit Document Scanner: автоматические границы, фильтры, многостраничный PDF.
- Исходный PDF всегда сохраняется отдельно в Documents/PrivateScan без обработки ИИ.
- Список файлов, поиск по имени, просмотр, отправка, переименование, удаление.
- **ИИ-распознавание PDF** с помощью OpenAI Responses API, модель `gpt-6.1-terra`: передаёт PDF и получает дословную транскрипцию текста на исходном языке, включая русский.
- Создаёт **отдельную OCR-копию** в PDF с векторной типографикой A4 и переносом строк. Файл можно открывать, выделять текст в поддерживающих PDF-просмотрщиках и копировать.
- Ручная кнопка «Распознать ИИ» возле документа с подтверждением отправки.
- Опциональная автоматическая обработка сразу после сканирования (выключена по умолчанию).
- API-ключ хранится зашифрованным AES-256-GCM в Android Keystore, никогда не хранится в репозитории, на сервере приложения, в логе или в APK.
- Запросы API отправляются по HTTPS с `store:false`.

## Принципиальные ограничения
- **Это тестовый прототип, не полный аналог Adobe Scan.**
- Это НЕ точная реставрация исходного макета, печатей и подписей. Оригинальный скан остаётся отдельным; OCR создаёт новый текстовый PDF. Комплексные таблицы могут менять структуру.
- ИИ может ошибиться в датах, суммах, инициалах, реквизитах, таблицах. Обязательно сверяйте результат с оригиналом.
- **Передача PDF в OpenAI — передача третьей стороне**. Не используйте с адвокатской тайной без самостоятельной правовой и организационной оценки.
- Даже при `store:false` API допускает стандартное хранение журналов для мониторинга злоупотреблений. Подробнее: https://developers.openai.com/api/docs/guides/your-data
- Нужны интернет и оплачиваемый OpenAI API-аккаунт. Подписка ChatGPT Plus/Pro не включает API-биллинг.
- PDF ограничен 10 МБ на запрос, сеть 180 секунд; длинные документы могут не поместиться в выходной лимит или превысить ограничения.
- Приложение не подключается напрямую к вашей истории или подписке ChatGPT — используется официальный OpenAI API.
- Работа с документами локально в Documents/PrivateScan (общая папка). Это не защищённое хранилище адвокатской тайны.
- Отображение и поиск извлечённого текста могут различаться между PDF-просмотрщиками. Аппаратное тестирование не проводилось.
- ML Kit Document Scanner зависит от Google Play Services и иногда требует первоначальную загрузку компонентов.

## Первый запуск ИИ
1. Создать API-ключ самостоятельно в https://platform.openai.com/api-keys — не отправлять его в чат и не публиковать на GitHub.
2. Отдельно настроить оплату API на https://platform.openai.com/settings/organization/billing/overview .
3. Открыть PrivateScan → «ИИ-распознавание · настройки» → ввести API-ключ → «Сохранить».
4. Сделать тестовый скан документа без личных и конфиденциальных сведений.
5. Нажать «Распознать ИИ → отдельный текстовый PDF», прочитать подтверждение.
6. В Documents/PrivateScan появится второй файл с пометкой `_OCR_...`. Сверить его по оригиналу.
7. По желанию включить отправку **всех новых сканов автоматически**. Не включать для конфиденциальных материалов.

## APK
GitHub → Actions → PrivateScan APK → последняя успешная сборка → Artifacts → PrivateScan-debug-apk → app-debug.apk.

Подпись — debug, только для тестирования. Для публичного распространения нужен отдельный ключ релизной подписи, политика конфиденциальности, тестирование и аудит безопасности.

## Сборка
Java 17, Gradle 8.10.2, Android SDK 35:
```
gradle -p scanner-app :app:assembleDebug
```
