# PrivateScan 0.3 — автономный сканер для Android

**Независимое приложение**, не Adobe, не официальный клиент ChatGPT.
Исходный код в отдельной ветке; CRM в `main` не изменялась.

## Что сделано

1. Google ML Kit Document Scanner через Google Play Services: съёмка, выравнивание, фильтры, обрезка, многостраничные PDF, импорт изображений.
2. Tesseract4Android 4.9.0 с **встроенными в APK** языковыми моделями rus+eng. Локальная обработка готового PDF без обращения к сети. Максимум 45 страниц и 45 МБ за обработку.
3. PdfBox-Android 2.0.27.0 дописывает в каждую страницу исходного PDF **невидимый Unicode-текст** по найденным координатам слов, оставляя скан неизменённым. Новый файл имеет суффикс `_SEARCHABLE_`.
4. Системная передача PDF в совместимые приложения нейросетей (ChatGPT, Claude, Gemini, Яндекс и другие). Файл отправляется только по явному подтверждению. Полученный из другого приложения готовый PDF можно импортировать через Android Documents Provider.
5. **Вход через подписку ChatGPT без API-ключа**: официальный open-source SIWC dynamic OAuth client с PKCE, временным локальным HTTP callback на 127.0.0.1, подтверждением прав `chatgpt.tokens.use.direct`, проверкой RS256 JWT по OpenAI JWKS, проверками issuer/audience/expiry/nonce и шифрованием токенов AES-GCM через Android Keystore. Пароли и API-ключи не нужны.
6. После входа отдельной кнопкой запускается **разовая передача PDF** в OpenAI Responses API с `store:false`, `stream:true`, выбором модели из каталога аккаунта. Возвращённый текст сохраняется в **отдельный текстовый PDF** `_CHATGPT_TEXT_`. Исходный скан не заменяется.
7. Можно отключить аккаунт ChatGPT (локальный сеанс очищается, удалённое прекращение сеанса запрашивается у OpenAI).

## Тестирование и ограничения

- GitHub Actions `PrivateScan APK` компилирует debug APK. **Нужен обязательный тест на Samsung**: разрешения, память, распознавание кириллицы, качество PDF, вход через ChatGPT и OAuth callback. Успешная компиляция не означает, что эти пути уже прошли проверку.
- Сканирование камерой использует Google Play Services и может при первом запуске подгрузить модули. После создания PDF **локальный OCR выполняется офлайн**.
- Слова с OCR ошибками могут попадать в скрытый слой; поиск и выделение текста нужно проверять, особенно на PDF с поворотом, сложной вёрсткой и таблицами.
- В режиме ChatGPT передача производится в OpenAI: **не использовать без надлежащей проверки условий обработки для документов с адвокатской тайной**. Предоставление разрешения на запрос расходует лимиты подписки, возможны дополнительные кредиты согласно настройкам ChatGPT.
- OAuth SIWC доступен в рамках официальной open-source программы, а доступные модели и поддержка PDF зависят от аккаунта и правил OpenAI. Отдельный запрос может быть отклонён сервером. Приложение **не получает доступ к чатам или памяти ChatGPT**.
- Cloud AI текстовый PDF содержит **перевёрстанный текст**, а не внешне идентичную копию. Для оригинального оформления используйте локальный `_SEARCHABLE_` PDF. Сверяйте даты, суммы, реквизиты по исходному изображению.
- **Не предлагайте APK как защищённое хранилище**. Файлы сохраняются в общей Documents/PrivateScan, доступны приложениям с разрешённым доступом.
- Эта версия имеет **новый package id `ru.family.privatescan.v03`**, чтобы можно было установить одновременно с 0.2 (предыдущие debug-подписи нестабильны). Документы 0.2 можно перенести через кнопку импорта PDF.
- Выпуск из GitHub Actions подписан **тестовым ключом**; для постоянных обновлений нужен фиксированный релизный ключ.

## Первые проверки

1. Установите `PrivateScan 0.3`.
2. Сделайте скан простого русского документа без персональных данных.
3. Нажмите «Создать поисковый PDF · RU/EN · без интернета». Откройте полученный `_SEARCHABLE_`, попробуйте выделить русское слово и найти его.
4. Нажмите «Подключить ChatGPT без API-ключа», пройдите официальный вход в браузере OpenAI и разрешите использование лимитов подписки.
5. Нажмите «ChatGPT по подписке → текстовый PDF» для тестового файла. Для документов с конфиденциальными данными используйте только локальное OCR.
6. Для резервного режима «Отправить в ChatGPT / Claude / Gemini / Яндекс» выберите совместимое приложение в системном меню. Результат импортируйте обратно вручную.

## Сборка

GitHub Actions → PrivateScan APK → успешный запуск → Artifacts → PrivateScan-debug-apk → `app-debug.apk`.

CI скачивает лицензированные открытые языковые модели Tesseract (`tessdata_fast`) и шрифт NotoSans-Regular по HTTPS, проверяет размеры и упаковывает в assets. Рекомендуется закрепить SHA256 скачиваемых моделей перед публичным релизом.

Java 17, Gradle 8.10.2, Android SDK 35, dependency JitPack:
```bash
gradle -p scanner-app :app:assembleDebug
```
