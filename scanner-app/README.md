# PrivateScan 0.6 — исправления по результатам Samsung-тестирования

## Что исправлено

- В каскадной камере над реальным четырёхугольным контуром документа рисуется **подвижная бирюзовая рамка**, при устойчивом документе — зелёная; в момент фокусировки — жёлтая. Если контур не обнаружен, показываются только статические направляющие (это не ложное обнаружение листа).
- После каждого снимка появляется крупная вспышка **«✓ СТРАНИЦА N СНЯТА»**, слышен звук затвора, увеличивается счётчик и появляется сообщение **«Уберите лист»**. Камера не снимает прежний лист повторно, пока он не исчезнет из кадра.
- Интерфейс камеры фиксирован в **книжной ориентации**. Обработанные снимки и итоговый PDF имеют **исключительно портретные листы ISO A4**. Альбомная фотография вписывается в портретную страницу без потери содержимого исходника; при обнаруженных углах страницы перспектива исправляется в A4.
- Исправлен выбор браузера ChatGPT: в предыдущей версии `AlertDialog.setMessage` и `setItems` использовались одновременно, из-за чего на Samsung отображалась только «Отмена». Теперь видны два действия: Chrome и системный браузер. Настоящее подключение считается успешным только после OAuth callback, проверки ID token и scopes — простой экран согласия не означает подключения.
- При продолжающемся зависании согласия OpenAI используйте локальный OCR либо системную кнопку «Отправить в ChatGPT» для конкретного PDF. Не отправляйте в чат параметры OAuth URL, cookie или токены.

## Сценарий проверки

1. Откройте «Каскадная съёмка» и наведите на полностью видимую страницу. Проверьте, совпадает ли рамка с краями листа.
2. Снимок должен быть сделан без кнопки, при этом появится вспышка, номер и будет слышен звук.
3. Уберите лист и поднесите второй. Повторите, после чего нажмите «Готово».
4. Откройте PDF: все листы должны быть **книжной ориентации A4**.
5. Подключите ChatGPT. Выберите Chrome, если системный браузер зависает на согласии.
6. Если OAuth так и не возвращается, пришлите **только текст статуса** PrivateScan, скрыв любые URL и данные авторизации.

## Условия

Это отдельный **тестовый Android-пакет `ru.family.privatescan.v06`**, чтобы сохранить установленные версии 0.4/0.5 при проверке. Последующие автообновления требуют неизменного package id и постоянной подписи keystore в GitHub Actions Secrets. Без этого функция «Проверить обновления» может проверить выпуск, но Android откажет в установке другого подписанного APK.

Исходники размещены только в отдельной ветке; CRM `main` не менялась. Компиляция GitHub не заменяет проверку камеры и OAuth на Samsung. Не тестируйте отправку ИИ на документах с адвокатской тайной.

# PrivateScan 0.5: каскадная съёмка, пакетная обработка PDF

Самостоятельное Android-приложение с открытым исходным кодом. Не является Adobe Scan или официальным приложением ChatGPT. Код расположен в отдельной ветке; ветка CRM `main` не изменена.

## Каскадная съёмка — без кнопок между листами

1. Нажмите **«Каскадная съёмка без кнопок»** только для открытия камеры.
2. Наведите камеру на лист так, чтобы видны были все четыре угла.
3. OpenCV обнаруживает контур, оценивает резкость и устойчивость положения (~5 анализируемых кадров и минимум 700 мс). CameraX запускает автофокус на центре документа и, после успешной фокусировки, самостоятельно фотографирует.
4. Уберите лист из кадра — приложение требует ~4 кадров без обнаруженного документа для предотвращения дублей. Положите и наведите новый лист: срабатывает новая автоматическая съёмка.
5. По окончании нажмите **«Готово · PDF» один раз**. Все фотографии пакетно исправляются по перспективе, приводятся к 300 dpi на A4, мягко повышается локальный контраст и резкость. Итог — единый многостраничный A4 PDF. Отдельный PDF с исходными снимками также сохраняется.
6. Если автоснимок не удаётся, есть альтернативный ручной сканер Google ML Kit. Максимум 40 листов в одном сеансе.

Обе PDF-копии сохраняются в Documents/PrivateScan. Фото обрабатываются **локально на Samsung, без отправки третьим сторонам**. Для поиска по распознанным словам используйте имеющееся локальное OCR RU/EN. Подписи и печати сохраняются цветными; алгоритм не дорисовывает символы или текст.

## Подключение ChatGPT: диагностика

На предоставленном пользователем скриншоте видна **реальная страница согласия auth.openai.com**, но кнопка подтверждения показывает бесконечный индикатор загрузки. Это свидетельствует о том, что начальная часть OAuth работает; **причина зависания не подтверждена** (браузер, сеть, cookies, ответ сервера или локальный callback). В приложении добавлен выбор **Chrome / браузер по умолчанию** и диагностика этапов авторизации. Нужно проверить возврат `127.0.0.1` и выданные scopes. Не копируйте в переписку URL с параметрами OAuth, токены, cookie, пароли.

Если Chrome также зависает, используйте локальное OCR, либо передавайте тестовый PDF через Android Share в официальное приложение ChatGPT и импортируйте итог обратно вручную. Прямую интеграцию нельзя считать исправленной до успешной проверки на телефоне.

## Обновление кнопкой

В главном экране кнопка **«Проверить обновления»** запрашивает GitHub Releases по HTTPS, сравнивает версии, загружает APK, сверяет SHA256, package id и сертификат подписи, затем вызывает стандартный установщик Android. Подмена APK или несоответствие подписи останавливают установку.

**Ограничение debug-сборок:** GitHub Actions выпускает APK со случайным временным debug-ключом, поэтому Android не разрешит обновление одной такой сборки другой. Для рабочего обновлятора нужно один раз создать **постоянный release signing key** и хранить его только как GitHub Actions Secret. Пользователь должен настроить секреты (не отправлять ключ в чат, не коммитить в публичный репозиторий). Подписанные одним ключом новые APK могут обновляться без удаления предыдущей версии, сохраняя данные. Номер пакета для 0.5 — `ru.family.privatescan.v05`; его нужно сохранить для будущих релизов.

## Иконка

Создана векторная иконка: тёмно-синий фон, белая страница, бирюзовые углы и линия сканирования.

## Безопасность и статус

- Этот релиз **тестовый**. Компиляция GitHub Actions не означает испытания автофокуса и распознавания границ на конкретном Samsung.
- Камера работает без облачной нейросети; однако пользователь сам решает, передавать ли выбранный PDF в ChatGPT, Claude, Gemini или Яндекс.
- Исходный скан сохраняется отдельно; проверяйте качество итоговых страниц.
- Перед тестом OAuth/ИИ не используйте документы с адвокатской тайной.
- Не удаляйте предыдущие версии и данные, пока новые функции не проверены.

## Зависимости

CameraX 1.5.3, OpenCV 4.12.0, PDFBox-Android, Tesseract4Android, ML Kit scanner. Java 17, Gradle 8.10.2, Android compileSdk 35.

## Проверка работоспособности

1. Установить 0.5, разрешить камеру, открыть каскадную съёмку.
2. Навести на первый лист, убедиться что фокусировка завершилась автоматическим снимком без прикосновения; убрать лист, повторить с другим.
3. Нажать «Готово», убедиться, что получен единый PDF A4 с 2+ страницами и сохранён исходный PDF.
4. Проверить «Подключить ChatGPT» в Chrome, зафиксировать статус без секретов.
5. Проверить кнопку обновления. Пока стабильная подпись не настроена, проверка и загрузка доступны, но install будет отклонён при несоответствии сертификата.
