# FamilyVPN — семейный Android-клиент WDTT Plus

**Статус:** ветка разработки. Android APK не собран и не проверен; действующий VPN-сервер не изменялся.

## Назначение
Упрощённый клиент для 11–20 членов семьи на базе [WDTT Plus](https://github.com/Ivan4537/WDTT-Plus), лицензия GPL-3.0-or-later.

## Обязательные требования
- Одна кнопка «Подключить / Отключить».
- Каждый персональный пароль выдаётся одному устройству; решение об авторизации принимает сервер. Не использовать главный пароль владельца как клиентский.
- На **любой подключённой Wi-Fi сети** VPN отключается, даже если это публичный Wi-Fi; приложение не должно разрешать повторный запуск при Wi-Fi. После возврата на мобильную сеть допускается восстановление только ранее запущенного пользователем туннеля.
- Никаких открытых локальных прокси для семьи и раскрытия секретов.
- Проверка обновлений донора **один раз в неделю**; выпуск семейного APK только после тестов и проверки совместимости.
- Пользователь подтверждает установку APK в Android. Сохранять неизменный собственный ключ подписи.
- Домашний Keenetic с Entware/Xray/sing-box обслуживается независимо от семейной Android-сборки.

## Подготовленные локальные исходники
В текущем чате подготовлен архив `FamilyVPN_WDTTPlus_weekly_wifi_auto_off_source.zip`.
В нём находятся исходные Kotlin-файлы, сценарий применения патча к донору v20, тесты и два GitHub Actions workflow. **Этот архив ещё нужно загрузить в ветку в виде отдельных исходных файлов; данная документация его не заменяет.**

Ожидаемая структура: `familyvpn/{README_RU.md,config/,tools/}`, а сценарии Actions лежат в `.github/workflows/` репозитория. Секреты подписи хранятся только в GitHub Actions Secrets, никогда в исходном коде.

## Важное о GitHub Actions
Scheduled workflows GitHub выполняются по расписанию **только из ветки по умолчанию**. Пока код находится в `familyvpn-development`, еженедельная проверка не запущена. После технической проверки нужно либо согласованно перенести workflow в `main`, либо создать отдельный репозиторий `advocate33/familyvpn` с собственной веткой по умолчанию. Изоляция второго варианта предпочтительна, поскольку основной репозиторий содержит CRM и сайт.

## Предстоящая проверка
1. Загрузить все подготовленные исходники в эту ветку.
2. Собрать debug APK в Actions и провести тест на Samsung, включая Wi-Fi ↔ LTE, звонки VK, выдачу и отзыв пароля.
3. Проверить подпись release APK, SHA-256 и обновление поверх предыдущей семейной версии с сохранением профиля.
4. Проверить реальную работу WDTT на VPS и восстановление из резервной копии перед раздачей семье.

**Никогда не размещать здесь:** SSH-пароли, закрытые ключи, пароли WDTT, клиентские `wdtt://` ссылки, VK-хеши и секреты Android signing keystore.
