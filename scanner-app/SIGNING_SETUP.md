# Постоянная подпись APK для обновлений кнопкой

Ветка 0.5 содержит обновлятор, который сверяет SHA256, package id и сертификат.
Установка более новой версии поверх текущей возможна **только при одинаковой подписи**.
GitHub Actions по умолчанию создаёт новый отладочный ключ при каждой сборке, поэтому такие APK не могут обновлять друг друга.

## Настройка один раз (Windows 11, JDK 17+)

1. Создайте локальную папку для секретного ключа (вне GitHub, CRM и облачных папок), например `D:\PrivateScanKeys`.
2. Откройте PowerShell и выполните, заменив `<ВАШ_ПАРОЛЬ>` только в интерактивном запросе (не отправляйте пароли в чат):

```powershell
mkdir D:\PrivateScanKeys
keytool -genkeypair -v -keystore D:\PrivateScanKeys\privatescan-release.jks -storetype PKCS12 -alias privatescan -keyalg RSA -keysize 3072 -validity 10000
```

3. Выпишите и храните офлайн пароли и alias. Создайте резервную копию JKS на отдельном защищённом носителе.
4. Конвертируйте keystore в base64 **локально** и сохраните полученный текст в буфере обмена, не публикуя:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("D:\PrivateScanKeys\privatescan-release.jks")) | Set-Clipboard
```

5. В GitHub откройте репозиторий → Settings → Secrets and variables → Actions → New repository secret. Создайте четыре секрета:

- `PRIVATESCAN_KEYSTORE_BASE64`: строка из буфера обмена
- `PRIVATESCAN_STORE_PASSWORD`: пароль хранилища
- `PRIVATESCAN_KEY_ALIAS`: `privatescan`
- `PRIVATESCAN_KEY_PASSWORD`: пароль ключа

6. Очистите буфер обмена и убедитесь, что JKS не попал в публичный репозиторий.
7. Пересоберите версию 0.5 и проверьте в журнале GitHub Actions сообщение `Stable signing activated`. **Только после этого** устанавливайте её как базовую версию для последующих обновлений. Будущие APK должны использовать то же package id `ru.family.privatescan.v05`, тот же сертификат и повышенный `versionCode`.

**ВАЖНО:** ранее установленную v0.5 с временным debug-ключом нельзя заменить постоянной подписью поверх — сначала сохраните/экспортируйте документы, затем удалите её и установите подписанную версию. Это действие требует отдельного подтверждения пользователя, автоматического удаления приложение не выполняет.

Ни мне, ни кому-либо в переписке не отправляйте содержимое JKS, base64-строку и пароли.
